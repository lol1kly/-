# CS2 Bomb Mode Arena — Online v28

## Что изменено
- В разделе «Мультиплеер» добавлена одна основная кнопка «ИГРАТЬ». Только она инициирует подключение браузера к серверу.
- Если пользователь ещё не вошёл, кнопка сначала подключает клиент; после регистрации/входа нужно нажать её ещё раз.
- Доступен только режим «Закладка бомбы».
- Быстрый подбор рассчитан на 1 на 1: первый игрок ждёт, второй подключается к комнате, после чего сервер сообщает обоим о старте матча.
- Команды назначаются случайно, но сбалансированно: при двух игроках каждый оказывается в своей команде.
- В онлайн-матче локальные боты отключены. Одиночная игра вне онлайн-матча сохраняется.

## Развёртывание на Render
1. Загрузите все файлы из этой папки в корень GitHub-репозитория.
2. Render Web Service: Build Command `npm install`, Start Command `npm start`.
3. Если сайт обслуживается самим Node-сервером, кнопка подключается к тому же домену через `wss://` при HTTPS.

## Ограничение
Это браузерный прототип мультиплеера, а не точная копия серверной симуляции CS2. Проверьте матч двумя отдельными аккаунтами/браузерами после публикации.
