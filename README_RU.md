# CS2 Bomb Mode Arena — Online v29

## Исправления v29
- Исправлено появление игроков: сервер заранее создаёт стартовые позиции игроков по командам и сразу рассылает снимок состояния.
- После первого клиентского пакета позиция помечается как реальная; проверка скорости применяется к последующим перемещениям, чтобы начальный spawn snapshot не блокировал первый пакет.
- В онлайн-матче Escape открывает диалог подтверждения вместо немедленного выхода.
- «Продолжить игру» закрывает диалог и возвращает управление; «Выйти в меню» отправляет серверу leave_room.
- Если игрок покидает матч или теряет соединение, сервер уведомляет соперника, но не назначает победителя и не увеличивает счёт. Матч останавливается без засчитанной победы.

## Развёртывание
1. Распакуйте архив.
2. Загрузите все файлы из папки в корень GitHub-репозитория, заменив старые версии.
3. Render Web Service: Build Command `npm install`, Start Command `npm start`.
4. Убедитесь, что сервис использует Node.js и что WebSocket подключается к тому же домену через `wss://` при HTTPS.
5. После публикации проверьте два отдельных аккаунта в двух браузерах/устройствах.

## Важно
Это исправление синхронизации и выхода, а не полная серверная симуляция уровня Counter-Strike 2. Двухустройственный тест в опубликованной среде здесь выполнить невозможно; после развёртывания требуется проверка реального матча.
