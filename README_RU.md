# CS2 Bomb Mode Arena — Online v30

## Исправления v30
- Исправлено появление игроков: сервер заранее создаёт стартовые позиции игроков по командам и сразу рассылает снимок состояния.
- После первого клиентского пакета позиция помечается как реальная; проверка скорости применяется к последующим перемещениям, чтобы начальный spawn snapshot не блокировал первый пакет.
- В онлайн-матче Escape открывает диалог подтверждения вместо немедленного выхода.
- «Продолжить игру» закрывает диалог и возвращает управление; «Выйти в меню» отправляет серверу leave_room.
- Если игрок покидает матч или теряет соединение, сервер уведомляет соперника, но не назначает победителя и не увеличивает счёт. Матч останавливается без засчитанной победы.

## Развёртывание
1. Распакуйте архив.
2. Загрузите все файлы из папки в корень GitHub-репозитория, заменив старые версии.
3. Render Web Service: Build Command `npm install`, Start Command `npm start`.
4. Убедитесь, что сервис использует Node.js и что WebSocket подключается к тому же домену через `wss://` при HTTPS.
5. После публикации проверьте два отдельных аккаунта в двух браузерах/устройствах.

## Важно
Это исправление синхронизации и выхода, а не полная серверная симуляция уровня Counter-Strike 2. Двухустройственный тест в опубликованной среде здесь выполнить невозможно; после развёртывания требуется проверка реального матча.


## Дополнительное исправление v30
- Сервер рассылает снимки игроков каждые 100 мс в активном матче, а не только после принятия клиентского движения.
- Клиент сохраняет последние сетевые координаты, если они приходят до готовности 3D-сцены, и применяет их после запуска матча.
- В онлайн-режиме локальные боты отключаются, чтобы матч был именно 1 на 1.
- В Render Logs добавлены сообщения о подключении и отключении WebSocket-клиентов.

После загрузки обновления проверьте Render Logs: должны появиться строки `[ws] connected`, а после входа — обмен сообщениями. Это исправление адресует вероятную причину потери начального снимка, но требует повторной проверки на двух реальных браузерах.


## v31: синхронизация игроков и раундов
- Исправлено локальное завершение раунда из-за отсутствия локальных ботов в онлайн-матче: в онлайне решение принимает сервер.
- Клиенты плавно отображают позиции соперника, полученные от сервера.
- Сервер управляет тайм-аутом раунда и отправляет состояние следующего раунда; клиенты сбрасывают локальное состояние при увеличении номера раунда.
- Проверено синтаксически; обязательно протестируйте матч на двух устройствах после публикации. Полная авторитетная физика движения/коллизий пока не реализована.
