# CS2 Arena 2.0
Изменения относительно v35:
- Полный арсенал CS в меню закупки; в режимах «бомба» и «заложники» оружие зависит от стороны (T/CT).
- Радар (союзники всегда, враги — вблизи).
- Деньги (800$) сбрасываются в каждой новой игре.
- Онлайн: выбор режима 1×1 / 2×2 / 5×5 и карты в меню, затем «Играть».
- Ранги уровня 1–10 (как на Faceit, на основе ELO) отдельно для каждого режима; считаются только за завершённые матчи.
Развёртывание — как в v35 (Render: `npm install` / `npm start`). Постоянное хранение рангов требует Render Disk + `DATA_DIR`.
