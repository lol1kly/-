# CS2 Bomb Mode Arena — Online v35

Полная переработка онлайн-режима 1×1 («Закладка бомбы»). Обновлять нужно **весь проект** (особенно `server.js` и `index.html`).

## Что было сломано и исправлено

**Соперник не появлялся / игра «зависала»**
- Аватар соперника создавался через `THREE.CapsuleGeometry`, которого нет в Three.js r128 → ошибка при каждом снимке, соперник никогда не рисовался. Заменено на `CylinderGeometry`.
- Ошибка внутри обработчика сообщений больше не ломает остальные сообщения (обработчик в `try/catch`).

**Соединение**
- Сессия удалялась при закрытии сокета → после любого обрыва клиент считал себя вошедшим, а сервер отвечал «Сначала войди». Теперь сессии живут 24 ч, клиент автоматически переподключается и отправляет `resume`.
- Добавлены keep-alive: `ping` клиента каждые 20 с и серверный WebSocket-ping каждые 25 с (Render закрывает «молчащие» соединения — комната ожидания исчезала).
- При обрыве во время матча даётся 15 секунд на возвращение, матч не засчитывается как поражение.
- Один аккаунт — одно активное соединение (новое вытесняет старое без выхода из комнаты).

**Движение**
- Скорость была перепутана: прицел снайперки ускорял игрока, обычная ходьба была медленнее офлайна. Теперь 6.5 (обычная) и 3 (в прицеле) — как в офлайне.
- Если клиент переставал слать ввод (диалог Esc, свёрнутая вкладка), сервер продолжал двигать игрока. Теперь устаревший ввод (>0.5 с) игнорируется.
- Угол `yaw` растёт без границ; после ~16 оборотов сервер отклонял ввод. Теперь угол нормализуется.
- Прыжок не теряется при склейке пакетов.
- На сервере появились **коллизии с картой** (стены, ящики, внутренние стены — те же размеры, что и в `buildArenaMap`). Раньше в онлайне можно было ходить сквозь укрытия.
- Снимки состояния 30 Гц (было 10 Гц) + плавная интерполяция камеры — раньше свой вид дёргался.

**Стрельба**
- Выстрелы **не проходят через стены/ящики**.
- Серверный счётчик патронов расходился с клиентской перезарядкой (после первого магазина «патроны закончились»). Патроны контролирует клиент, сервер ограничивает темп стрельбы и список оружия.
- Прицел берётся в момент клика (без отдачи этого же выстрела).
- Счётчик убийств в HUD увеличивался на каждое попадание, теперь — только на убийство.

**Раунды и матч**
- Между раундами сервер не возвращал игроков на спавн — камера «прыгала» на старое место. Теперь позиции, здоровье и состояние сбрасываются.
- Добавлена настоящая заморозка (5 с) с серверным временем; таймеры клиента синхронизируются с часами сервера.
- Матч до **7 побед в раундах**; по окончании — экран итога и кнопка «В меню». Кнопка «новый раунд» в онлайне скрыта (раньше запускала локальный раунд).
- Если в раунде с установленной бомбой погиб террорист, раунд не заканчивается (бомбу нужно обезвредить или она взорвётся).
- Комната после ухода соперника закрывается — в неё больше не подселяет новых игроков со старым счётом.
- **Статистика аккаунта** (матчи/победы/убийства/смерти) теперь действительно обновляется. Уход из матча победу не засчитывает.
- Отпускание **E** отменяет установку/обезвреживание.

**Гранаты**
- Раньше граната зависала в воздухе. Теперь полёт, отскоки, взрыв и урон HE/молотова считает сервер, все клиенты видят одно и то же. Флэшка ослепляет противника. Лимит — 4 гранаты за раунд.

**Безопасность**
- Раньше любой мог скачать `/data/users.json` (хеши паролей) и `/server.js`. Теперь HTTP отдаёт только игру.
- Ограничение попыток входа/регистрации (12 в минуту с IP), защита от флуда сообщений, имена без учёта регистра, защита от `__proto__`-имён.

## Развёртывание (Render)
1. Загрузите все файлы в корень репозитория, заменив старые.
2. Build `npm install`, Start `npm start` (в `render.yaml` уже есть `/healthz`).
3. Manual Deploy → Deploy latest commit. В логах должна появиться строка `CS2 Bomb Mode Arena v35 server`.
4. Проверьте матч в двух браузерах (или обычное + инкогнито), два разных аккаунта.

## Важно знать
- На бесплатном Render диск **временный**: `data/users.json` (аккаунты и статистика) стирается при каждом деплое/перезапуске. Для постоянного хранения нужен Render Disk (платный план) — тогда задайте переменную `DATA_DIR` на путь диска.
- Онлайн всегда играется на карте dust2 (серверные коллизии построены под неё).
- Покупки/экономика остаются клиентскими; сервер проверяет только оружие, темп стрельбы и лимиты гранат.
- Автотесты сервера (движение, коллизии, стены, раунды, конец матча, статистика, переподключение, гранаты) пройдены. Реальный матч в двух браузерах в этой среде запустить нельзя — после деплоя проверьте вручную.
